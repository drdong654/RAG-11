# Vildly — текущая архитектура

| Поле | Значение |
|---|---|
| Статус | As-is, 1 сентября 2026 года |
| Интерфейс | Telegram-бот |
| Backend | FastAPI + SQLAdmin |
| Хранилище | PostgreSQL 16 + pgvector |
| RAG | Не интегрирован |

## Назначение

Vildly — прототип образовательного Telegram-бота. Текущая версия регистрирует пользователей, показывает меню и курсы, начинает сценарий записи на урок и предоставляет HTTP-интерфейс к пользователям. RAG, hybrid search, MCP и Discord пока не входят в работающий runtime.

## Контекст

```text
Telegram user -> Telegram Bot API -> aiogram bot
                                      |
                                      v
                              RegistrationService
                                      |
                                      v
FastAPI / SQLAdmin ----------> UserRepository ----------> PostgreSQL
```

Bot и API работают отдельными процессами, но используют общие SQLAlchemy models, repository и базу.

## Компоненты

| Компонент | Файл | Роль |
|---|---|---|
| Telegram runtime | `bot/main.py` | handlers, FSM, polling |
| Telegram UI | `bot/keyboard.py` | reply/inline keyboards |
| Service layer | `services.py` | регистрационные правила и DB sessions |
| Repository | `bot/db/repositories/users.py` | PostgreSQL CRUD/upsert |
| Model | `bot/db/models.py` | таблица `users` |
| DB infrastructure | `bot/db/engine.py` | engine, sessionmaker, `create_all` retry |
| HTTP API | `api/main.py` | endpoints и SQLAdmin setup |
| Admin view | `api/admin.py` | представление `User` |
| Deployment | `compose.yaml`, `Dockerfile` | контейнеры и runtime |

## Точки входа

- Bot: `uv run --no-sync python -m bot.main`.
- API: `uv run --no-sync uvicorn api.main:app --host 0.0.0.0 --port 8000`.
- Docker Compose: отдельные `db`, `api`, `bot`.
- Dockerfile default: `scripts/start.sh`, API в фоне и bot в foreground.

Bot проверяет `TOKEN` и `DATABASE_URL` при импорте. Bot и API вызывают `init_models()` на старте.

## Telegram-сценарии

| Действие | Поведение |
|---|---|
| `/start`, `Start` | Приветствие и меню по статусу регистрации |
| `/help`, `Help` | Справка |
| `/profile`, `Profile` | Проверка регистрации |
| `/login`, `Login` | FSM: Telegram contact, затем email |
| `/courses`, `Courses` | Inline-меню курсов |
| `Book a Lesson` | Проверка регистрации и placeholder разработки |
| `Back` | Очистка FSM и меню по статусу регистрации |

Регистрация принимает только contact текущего Telegram account. `RegistrationService` валидирует данные, `UserStorage` открывает async session, `UserRepository` выполняет PostgreSQL upsert. FSM хранится в памяти процесса и теряется при рестарте.

## FastAPI

| Метод | Путь | Результат |
|---|---|---|
| `GET` | `/users` | Все пользователи |
| `GET` | `/users/{telegram_id}` | Пользователь или 404 |
| — | `/admin` | SQLAdmin UI |

Авторизация отсутствует. API возвращает ORM instances без явных Pydantic response schemas.

## PostgreSQL и модель данных

Подключение: SQLAlchemy async + asyncpg. Repository использует PostgreSQL `insert().on_conflict_do_update()`.

`users`: `telegram_id` primary key; nullable `username`, `first_name`, `last_name`, `phone_number`, `email`; `created_at` с Python default. Email объявлен unique в модели; существующей БД требуется миграция.

Alembic отсутствует. Схема создаётся через `Base.metadata.create_all()`.

## Тесты

- Unit: успешная регистрация, повторный пользователь, повторный email.
- Integration: PostgreSQL upsert/read; требуется отдельный `TEST_DATABASE_URL`.
- Unit suite покрывает регистрацию, Telegram contact, course callbacks, lesson placeholder и Back.
- Нет тестов API, SQLAdmin, security, migrations, failures и RAG.

## Legacy и проблемы

SQLite остался в `aiosqlite`, `data/users.db` и документации. Активный код использует PostgreSQL.

Основные риски:

- PII доступна через API/admin без auth;
- существующей БД нужна миграция для unique email;
- DB credentials захардкожены в Compose;
- нет Alembic и DB healthcheck;
- course buttons и `Book a Lesson` пока отвечают placeholders вместо бизнес-сценариев;
- root-level `services.py` зависит от запуска из repo root;
- незавершённый RAG-код не подключён к runtime.

## Границы версии

Реализовано: Telegram UI, регистрация, PostgreSQL persistence, read-only user API, SQLAdmin, Docker Compose.

Не реализовано: завершённая запись на урок, управление курсами, auth, RAG pipeline, citations, MCP, Discord, migrations и observability.
