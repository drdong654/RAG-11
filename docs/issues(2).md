# Issue: Создаем бота

## Part 1. Создаем бота в Telegram

Нам понадобится:

* Создаем уникальный API Key для бота.
* Создаем каркас при помощи aiogram.
* Реализовать команду `/start`.
* Начинаем прописывать функцию обработки сообщений.

---

## Part 2. Подключаем Agno

* Установить библиотеку Agno.
* Создать каркас базового Агента.
* Подключить LLM.

---

## Part 3. Загрузка документа в Базу Знаний

* Создать папку БД (где хранится База знаний).
* Добавить туда Документы.
* Настройка Базы знаний.
* Выполнить индексацию документов.

---

## Part 4. Реализация RAG системы

* Реализовать поиск по Базе знаний.
* Настроить получение релевантного контекста.
* Передавать контекст в LLM.
* Формировать ответ на основе найденной информации.

---

## Part 5. Интеграция Telegram + RAG

* Связать Telegram-бота и RAG-систему.
* Передавать запрос пользователя в Агент.
* Получать ответ от RAG.
* Отправлять ответ пользователю в Telegram.
