## Tips for editing

- Italicised text inside each file is a placeholder. Replace it with your own content, then remove the italics.
- Internal links are relative paths to other `.md` files — they work both on GitHub and in any markdown editor.
- Keep these documents short. One screen per artefact is plenty for a small project.
