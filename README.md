# 🚀 RAG Assistant for Programming School

Интеллектуальный AI-бот для Discord и Telegram, разработанный для автоматизации взаимодействия с учениками школы программирования и быстрого доступа к внутренней базе знаний.

---

## 📖 Описание проекта

Проект основан на архитектуре **RAG (Retrieval-Augmented Generation)** и использует **Hybrid Search** *(semantic + keyword search)* для поиска релевантной информации по:

- учебным материалам;
- документации;
- FAQ;
- внутренним данным школы.

Система поддерживает интеграцию через **MCP (Model Context Protocol)**, что позволяет подключать внешние инструменты, базы знаний и AI-сервисы в единую инфраструктуру.

---

## ⚡ Основные возможности

- 🤖 AI-ассистент для учеников;
- 🔎 Hybrid Search (semantic + keyword retrieval);
- 📚 Работа с внутренней базой знаний;
- 💬 Поддержка Discord и Telegram;
- 🧠 Генерация ответов через LLM;
- 🔌 MCP-интеграции;
- 🐳 Docker deployment;
- 🗂 Масштабируемая архитектура.
